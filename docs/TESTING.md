# 시험 기준

자동 테스트는 다음 명령으로 실행합니다.

```bash
swift test
```

공개 Release 전에는 아래 실기기 시험도 필요합니다.

## 필수 조합

- 지원하는 최소 macOS 버전과 현재 macOS 버전
- iPadOS/iOS 17 이상에서 최소 두 가지 기기
- 일반 공유기, 개인 핫스팟, 가능한 경우 학교 Wi-Fi
- Apple TV 미사용, Apple TV 먼저 연결, ClassMirror 먼저 연결

## 반복 시험

| 시험 | 기준 |
| --- | --- |
| PIN 연결·해제 | 조합별 30회, 잘못된 PIN 후 정상 재시도 포함 |
| 회전 | 가로/세로 100회, 화면 비율과 창 상태 유지 |
| 전체 화면 | 진입/종료 30회, 초록 버튼·더블클릭·단축키 |
| 지속 실행 | 40분 3회, 60분 1회, 120분 1회 |
| 네트워크 복구 | AP 단절·복귀 후 앱 재실행 없이 다시 수신 가능 |
| Apple TV 병행 | 두 연결 순서에서 영상과 오디오 유지 |

## 기록

```text
버전 / 커밋:
Mac / macOS:
송신 기기 / OS:
Apple TV / tvOS:
네트워크 종류와 대역:
연결 모드와 순서:
실행 시간:
영상 크기 / 움직임 중 FPS:
오디오 코덱과 출력:
CPU / 메모리:
자연 단절 / crash / 복구 실패:
결론과 재현 절차:
```

개인 기기명, Apple ID, IP 주소, 학생 자료와 음성은 기록하지 않습니다.

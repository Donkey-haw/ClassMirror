# 로드맵

## v0.1 — 공개 Alpha와 교실 안정화

- 단일 iPad/iPhone 영상·오디오 수신
- PIN, 회전, 전체 화면, 항상 위, 재연결
- Apple TV 동시 사용
- GPLv3 소스와 재현 가능한 DMG
- Developer ID 서명·공증
- macOS 15 및 장시간 실기기 시험표

## v0.2 — 네트워크 복구와 P2P 연구

- 학교 Wi-Fi 진단 개선
- AWDL 직접 연결 호환성 연구
- Apple TV와 P2P 자원 충돌 조사
- OS 업데이트별 receiver 회귀 시험

P2P는 검증 결과에 따라 실험 기능으로 유지하거나 제외할 수 있습니다.

## 이후 검토

- 다중 기기 세션 관리자
- OBS 전용 입력
- OpenDisplay/DisplayBridge 입력 모듈
- 자동 업데이트

녹화, 계정, 클라우드, 원격 조작은 현재 제품 범위가 아닙니다.

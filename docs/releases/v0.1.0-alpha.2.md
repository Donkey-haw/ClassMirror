# ClassMirror v0.1.0-alpha.2

ClassMirror 전용 macOS 앱 아이콘을 추가한 공개 Alpha입니다. Finder,
응용 프로그램 폴더, Dock과 앱 전환기에서 ClassMirror를 쉽게 구분할 수
있습니다.

> 이 DMG는 아직 Apple Developer ID로 서명·공증되지 않았습니다. macOS가
> 첫 실행을 막을 수 있으며 시스템 설정 → 개인정보 보호 및 보안에서
> 사용자가 직접 승인해야 합니다. 중요한 수업 전에 반드시 시험하세요.

## 변경 사항

- Mac 창과 iPad 화면 미러링을 형상화한 전용 앱 아이콘
- 표준 16px~1024px macOS 아이콘 크기를 포함하는 `AppIcon.icns`
- Debug 및 자체 포함 Release 앱 모두 같은 아이콘 사용
- README에 앱 아이콘 표시

앱의 AirPlay 수신, PIN, 영상, 오디오와 Apple TV 동시 사용 기능은
`v0.1.0-alpha.1`과 같습니다.

## 설치

1. `ClassMirror-0.1.0-alpha.2-macos-arm64.dmg`를 받습니다.
2. 함께 제공되는 SHA-256을 확인합니다.
3. DMG에서 ClassMirror를 Applications로 드래그합니다.
4. [설치 안내](https://github.com/Donkey-haw/ClassMirror/blob/v0.1.0-alpha.2/docs/INSTALLATION.md)에 따라 처음 실행합니다.

`ClassMirror-0.1.0-alpha.2-source.tar.gz`에는 바이너리에 대응하는 전체 소스,
빌드 스크립트와 고정된 OpenSSL·libplist 원본이 포함되어 있습니다.

# 문제 해결

문제가 지속되면 ClassMirror와 송신 기기의 OS 버전, 네트워크 종류, 재현
절차를 기록해 GitHub Issue로 알려 주세요. 개인 기기명, IP, 학생 화면은
제거하세요.

## 화면 미러링 목록에 ClassMirror가 없음

1. ClassMirror 창이 `연결 대기 중`인지 확인합니다.
2. 로컬 네트워크 모드라면 Mac과 iPad/iPhone이 같은 LAN에 있는지
   확인합니다.
3. 시스템 설정 → 개인정보 보호 및 보안 → 로컬 네트워크에서 ClassMirror를
   허용합니다.
4. macOS 방화벽이나 보안 도구가 수신 연결을 막는지 확인합니다.
5. ClassMirror에서 `수신기 다시 시작`을 누릅니다.
6. 다른 일반 공유기 또는 개인 핫스팟에서 비교합니다.

같은 Wi-Fi 이름을 사용해도 학교망이 mDNS, multicast 또는 기기간 통신을
차단할 수 있습니다. ClassMirror는 AP Isolation을 우회할 수 없습니다.

## PIN을 올바르게 입력해도 반복됨

- Mac에 현재 표시된 최신 PIN인지 확인합니다. 새 인증 요청이 오면 이전
  PIN은 더 이상 유효하지 않습니다.
- iPad/iPhone에서 연결 시도를 취소하고 ClassMirror가 다시 대기 상태가
  된 뒤 한 번 더 선택합니다.
- 문제가 남으면 ClassMirror의 `수신기 다시 시작`을 한 번 실행합니다.
- 재현 시 처음 실행 직후인지, 정상 연결을 끊은 뒤인지 Issue에 적어 주세요.

## 5초 안에 연결이 끊어짐

- 신호 품질보다 먼저 학교망의 client isolation 여부를 다른 공유기와
  비교합니다.
- Mac 또는 iPad의 VPN과 네트워크 필터를 잠시 해제할 수 있는 환경에서
  비교합니다.
- `학교망 직접 연결 (실험적)`과 로컬 네트워크 모드를 바꿔 시험할 때에는
  반드시 수신기를 다시 시작합니다.
- Apple TV 동시 사용 중이라면 로컬 네트워크 모드를 선택합니다.

## 영상이 끊기거나 FPS가 낮음

- Mac과 iPad를 5GHz/6GHz Wi-Fi 또는 혼잡이 적은 AP에 연결합니다.
- 대용량 다운로드와 화면 공유를 잠시 중단하고 비교합니다.
- 학교망이 아닌 개인 핫스팟에서 비교해 앱과 네트워크 원인을 분리합니다.
- 정지 화면에서는 송신 프레임 자체가 줄 수 있으므로 실제 필기나 스크롤
  중의 FPS로 판단합니다.

## 오디오가 나오지 않거나 끊김

- 설정 → 오디오에서 `기기 오디오 재생`이 켜져 있는지 확인합니다.
- 플레이어와 메뉴바의 음소거 상태를 확인합니다.
- macOS 제어 센터에서 올바른 출력 장치를 선택합니다.
- DRM 보호 앱 대신 일반 웹 영상 또는 로컬 비보호 영상으로 비교합니다.
- 영상도 동시에 끊기면 오디오만의 문제가 아니라 네트워크 문제일 가능성이
  큽니다.

## Apple TV와 동시에 사용할 수 없음

설정 → 연결에서 `Apple TV 동시 사용 (권장)`을 선택하고 수신기를 다시
시작하세요. `학교망 직접 연결 (실험적)`의 AWDL과 Mac의 Apple TV 송출은
같은 무선 경로에서 충돌할 수 있습니다.

## 전체 화면이 되지 않음

영상 영역을 더블클릭하거나 `⌘ Enter`를 누릅니다. macOS 초록색 창 버튼도
시스템 전체 화면을 사용합니다. 화면 상단 왼쪽의 초록 버튼이 확대 동작으로
설정된 경우 Option 키를 누르지 않은 상태에서 클릭하세요.

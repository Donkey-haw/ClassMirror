# 사용 설명서

## 처음 연결하기

1. Mac에서 ClassMirror를 실행합니다.
2. 창에 `연결 대기 중`과 수신 이름이 표시되는지 확인합니다.
3. iPad 또는 iPhone에서 제어 센터를 엽니다.
4. **화면 미러링**을 누릅니다.
5. ClassMirror 창에 표시된 수신 이름을 선택합니다.
6. Mac에 PIN이 나타나면 송신 기기의 입력 창에 그대로 입력합니다.
7. 첫 영상이 도착하면 같은 ClassMirror 창이 플레이어로 전환됩니다.

별도 iOS 앱이나 동일 Apple ID는 필요하지 않습니다.

## Apple TV와 동시에 사용하기

ClassMirror의 기본 연결 모드는 **Apple TV 동시 사용 (권장)**입니다.

1. Mac과 iPad/iPhone을 서로 통신 가능한 같은 LAN에 연결합니다.
2. ClassMirror 설정 → 연결에서 `Apple TV 동시 사용 (권장)`을 선택합니다.
3. 연결 방식을 변경했다면 ClassMirror 창에서 수신기를 다시 시작합니다.
4. Mac을 Apple TV에 연결합니다.
5. iPad/iPhone에서 ClassMirror로 화면 미러링을 시작합니다.

반대 순서로 연결해도 사용할 수 있습니다. ClassMirror는 Mac의 디스플레이
출력 대상을 직접 변경하지 않습니다. Apple TV에 Mac 전체 화면을 보내면
ClassMirror 창도 일반 Mac 창처럼 함께 표시됩니다.

`학교망 직접 연결 (실험적)`은 AWDL을 사용하며 같은 Wi-Fi가 아니어도
발견될 가능성을 시험하는 기능입니다. 이 모드는 Mac의 Apple TV AirPlay
송출과 충돌할 수 있으므로 두 기능을 동시에 사용할 때 선택하지 마세요.

## 화면 조작

| 동작 | 방법 |
| --- | --- |
| 시스템 전체 화면 | 영상 더블클릭, 초록색 창 버튼 또는 `⌘ Enter` |
| 전체 화면 종료 | 영상 더블클릭 또는 `⌘ Enter` |
| 오디오 음소거 | 화면 버튼 또는 `⌘ ⇧ M` |
| 항상 위 | 메뉴바 또는 `⌘ K` |
| 연결 해제 | 화면/메뉴바 버튼 또는 `⌘ D` |
| 창 크기 | 플레이어 하단의 맞춤, 50%, 75%, 100% |

전체 화면에서 포인터를 움직이면 하단 제어 막대가 잠시 나타납니다. 기기를
회전해도 현재 전체 화면 또는 최대화 상태를 유지하도록 설계되어 있습니다.

## 설정

### 일반

수신 이름은 iPad/iPhone의 화면 미러링 목록에 표시됩니다. 변경한 이름은
수신기를 다시 시작한 뒤 적용됩니다. 개인 이름 대신 교실을 구분할 수 있는
이름을 권장합니다.

### 연결

- **Apple TV 동시 사용 (권장):** 같은 LAN에서 수신하며 Apple TV 송출과
  함께 사용할 수 있습니다.
- **학교망 직접 연결 (실험적):** AWDL 기반 실험 모드입니다. Apple TV와
  충돌할 수 있습니다.

### 보안

기본값은 PIN 필요입니다. 학생이 있는 네트워크에서는 PIN을 유지하세요.
PIN이 교실 화면에 보인다면 화면을 본 사람도 입력할 수 있으므로, PIN을
교사 신원 인증 수단으로 간주해서는 안 됩니다.

### 오디오

`기기 오디오 재생`을 끄면 다음 수신 세션에서 기기 오디오를 재생하지
않습니다. 재생 중에는 화면의 음소거 기능으로 즉시 제어할 수 있습니다.

## 수업 전 권장 점검

- 사용할 교실 네트워크에서 목록 검색과 PIN 연결 확인
- Apple TV 사용 시 두 방향의 연결 순서 확인
- Mac의 음량과 오디오 출력 기기 확인
- 5분 이상 필기, 회전, 영상, 오디오 시험
- 실제 수업 시작 전 불필요한 다른 AirPlay 수신기 종료
